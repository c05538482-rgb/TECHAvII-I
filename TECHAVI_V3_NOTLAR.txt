BİLDİRİM İÇİN:
- Site HTTPS üzerinde olmalı.
- VAPID_PUBLIC_KEY ve VAPID_PRIVATE_KEY Render ortam değişkenlerinde olmalı.
- Anahtar üretmek için: npm run vapid
- Kullanıcı giriş yaptıktan sonra sağ alttaki “Bildirimleri Aç/Yönet” düğmesini kullanır.
- Düğme mevcut aboneliği onarabilir ve gerçek test bildirimi gönderir.

GOOGLE GİRİŞ:
- Google Cloud Console'dan Web OAuth Client ID oluşturun.
- Render'a GOOGLE_CLIENT_ID olarak ekleyin.
- Ayarlanmazsa Google düğmesi gizli kalır; normal e-posta/şifre girişi çalışır.
